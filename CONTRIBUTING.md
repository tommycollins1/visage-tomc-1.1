# Contributing to ViSAGE

Thank you for your interest in contributing to ViSAGE.

## Code Style
- Follow the existing modular structure:
  `data → behaviour → model → scenario → visualisation → examples`
- Use clear, descriptive docstrings.
- Avoid adding unused or placeholder modules.

## Adding New Features
- New behavioural components → `src/behaviour/`
- New model components → `src/model/`
- New scenario types → `src/scenario/`
- New visualisations → `src/visualisation/`

## Pull Requests
- Describe the purpose of the change.
- Include tests or example scripts where appropriate.
- Update the CHANGELOG and VERSION if the change is significant.

## Reporting Issues
Please include:
- Steps to reproduce
- Expected behaviour
- Actual behaviour
- Environment details (Python version, OS)
